# Mr. Reagan Classroom Nameplate

I want to design a modular teacher desk nameplate for my classroom.

This should be a premium, Etsy-worthy classroom product - a gift-quality
piece, not a rough first draft. The lettering should be anime-inspired in
style (general aesthetic influence only, not a reproduction of any
copyrighted character or logo - see docs/licensing-policy.md), with a
raised, multi-color look.

It needs to be modular so it can be reprinted or resized without
redesigning the whole piece, and it must be AMS compatible for multi-color
printing on a Bambu printer. The nameplate should fit along the front edge
of a standard 48-inch teacher desk.

Material: PLA. This is meant to sit on a teacher's desk in a classroom, so
students can see it - not a functional/mechanical part, just a display
and identification piece.
